# KanbanApp for VSCode

完全オフライン・セキュア環境で動作する、VSCodeネイティブのカンバン型タスク管理拡張機能です。
コーディング作業とタスク管理をシームレスに行き来し、業務データを外部に送信することなく安全に管理できます。

---

## 🎯 概要・特徴

- **完全オフライン動作**: 外部通信を一切行わず、すべてのデータはVSCodeのローカルストレージに保存されます。企業内の監視・プロキシ環境でも問題なく動作します。
- **VSCode統合**: アクティビティバーからワンクリックでボードを開け、コーディング作業とタスク管理をシームレスに切り替えられます。
- **ダークテーマ（Obsidian風）デザイン**: VSCodeのダークテーマに調和する、目に優しく視認性の高いUIを採用しています。
- **リッチなメモ機能**: マークダウン対応、クリップボードからの画像直接ペースト対応。

---

## 🚀 使い方ガイド

### 基本的な使い方

- **タスクの追加**: 画面右下の `＋` ボタン、または `Ctrl + N` で新規タスクを作成できます。
- **画面の切り替え**: `Ctrl + T` (または `Shift + Ctrl + T`) で、カンバン → リスト → タイムライン の3画面を切り替えます。
- **カンバン表示**: ドラッグ＆ドロップでステータス変更・並び替え。「待機」タスク用の隠しパネルも搭載。
- **リスト表示**: 複数ステータスの高度なフィルタリングや、テーブルヘッダーでのソートに対応。
- **タイムライン表示**: タスクの着手予定日・期限をガントチャート形式で一覧表示。期間の伸縮や依存関係の確認が可能です。

### 便利なウィジェット（右サイドバー）

`Shift + Ctrl + B` でウィジェットパネルを開閉できます。

- **Quick Resource Hub**: メモ内に記載されたURLリンクやローカルファイルパス（`file://〜`）を自動抽出し、タスク単位でグループ化。ワンクリックで対象のリソースを開けます。
- **Light Progress Tracker**: メモ内に記載された `#タグ` を抽出し、タグごとの進捗状況（プログレスバー）とタスク一覧をツリー状に表示します。

## ⌨️ ショートカットキー一覧

以下のショートカットは、KanbanAppパネルがアクティブな時のみ有効です。

| ショートカット     | 機能                                   |

| `Ctrl + N`         | 新規タスク作成                         |

| `Shift + Enter`    | モーダルでの保存                       |

## 📦 導入方法（VSIXからのインストール）

このアプリは、VSIXファイル（`kanbanapp-vscode-1.0.0.vsix`）単体でインストール・動作が可能です。インターネット接続は不要です。

1. VSCodeを開く
2. 左サイドバーの「拡張機能（Extensions）」アイコンをクリック
3. パネル右上の「`...`（表示およびその他のアクション）」をクリック
4. **「VSIXからのインストール... (Install from VSIX...)」** を選択
5. 配布された `.vsix` ファイルを選択
6. インストール完了後、アクティビティバー（左端のアイコン列）に追加されたカンバンアイコンをクリックし、「ボードを開く」ボタンを押す

## 💾 データの保存場所とバックアップ

すべてのデータはVSCodeのグローバルストレージ内に保存されます。PCの移行やバックアップの際は、以下のフォルダをそのままコピーしてください。

**Windowsの場合のパス例:**

```text
C:\Users\【ユーザー名】\AppData\Roaming\Code\User\globalStorage\user.kanbanapp-vscode\
  ├── kanban.db       ← タスクデータ（SQLiteデータベース）
  ├── config.json     ← アプリの設定・タブ構成
  └── images/         ← メモに貼り付けた画像ファイル
```

_(新PCに移行する場合は、新PCで一度拡張機能を開いて初期フォルダを生成させた後、旧PCのデータを上書きコピーしてください。)_

## 🔄 旧アプリ（Tauri版など）からのデータ移行

以前のスタンドアロン版アプリで使用していたデータを引き継ぐ場合は、以下の手順でファイルをコピーしてください。

1. **移行元ファイルの準備**
   旧アプリのデータ保存先（例: アプリの実行フォルダ内の `data/` フォルダ、または `%APPDATA%\旧アプリ名\` など）から、以下のファイル・フォルダを見つけます。
   - `kanban.db`
   - `config.json`
   - `images/` フォルダ（存在する場合）

2. **VSCode側の初期化**
   VSCodeでこの拡張機能をインストールし、一度アクティビティバーから「ボードを開く」を実行します。（これにより、移行先となる空のデータベースとフォルダが生成されます）

3. **VSCodeの終了とファイルの上書き**
   VSCodeを完全に終了させます。その後、上記1で見つけた旧アプリのファイル一式を、以下の移行先フォルダに**上書きコピー**します。
   - **移行先**: `%APPDATA%\Code\User\globalStorage\user.kanbanapp-vscode\`

4. **確認**
   VSCodeを再度起動しボードを開くと、旧アプリのタスクデータや設定、画像がすべて復元されています。

## 🗑️ アンインストール

## 🛠️ 開発者向けガイド

ソースコードからビルド・パッケージングを行う場合の手順です。

### 前提条件（システム要件）

開発・ビルドを行うには以下の環境が必要です。

- **Node.js**: v18以上 (v20以上を推奨)
- **npm**: v9以上
- **VSCode**: v1.86.0以上

### 1. 依存関係のインストール

```bash
npm install
```

### 2. 開発モードでの起動（動作確認）

1. VSCodeでこのプロジェクトフォルダ（`kanbanAPP_React`）を開く
2. `F5` キーを押して Extension Development Host を起動
3. 開いた新しいVSCodeウィンドウで、アクティビティバーのアイコンから「ボードを開く」を実行
   > フロントエンドや拡張機能のコードを変更した場合は、都度 `npm run build` を実行し、開発ホスト側で `Ctrl+R`（ウィンドウの再読み込み）を行うことで変更が反映されます。

### 3. 本番用ビルドとパッケージング（VSIX作成）

本番用にWebviewと拡張機能のソースをビルドし、配布用の `.vsix` ファイルを生成します。

```bash
npm run package
```

> 内部で `npm run build` と `npx @vscode/vsce package` が自動的に実行されます。成功するとプロジェクトルートに `kanbanapp-vscode-1.0.0.vsix` が生成されます。
